## 一、目标电脑要求

| 项目 | 要求 | 说明 |

## 二、部署步骤（目标电脑）

1. 把整个 `VocalSeparator` 文件夹拷到目标电脑任意位置，例如 `D:\VocalSeparator`。
   - 路径建议**不要含中文和空格**，可减少个别依赖的编码问题。
   - 不要只拷单个文件，`models`、`bin` 两个子目录必须一起拷。
2. 进入该文件夹，**双击 `一键安装.bat`**。
3. 脚本会自动依次完成：

   - 查找本机 Python（优先 3.12 → 3.11 → 3.10）；
   - 在本包目录内创建 `venv` 虚拟环境（不污染系统 Python）；
   - 从 PyTorch 官方源装 `torch / torchaudio / torchvision`（CUDA 12.8 版），再从清华 / 阿里镜像装 `requirements.txt` 其余依赖；
   - 校验环境（能否 import 关键库、CUDA 是否可用、模型数量、FFmpeg 是否就位）；
   - 在桌面创建快捷方式 `VocalSeparator.lnk`。

4. 看到 `安装完成` 后，关闭窗口即可。

耗时参考：网速正常时 **10 ~ 25 分钟**（大头是 torch 下载安装），与本机实测相当。

## 三、启动与使用

- 双击**桌面快捷方式 `VocalSeparator`**，或双击包内 `start.bat`。
- 浏览器会自动打开本地页面（默认 `http://127.0.0.1:7861`）。
- 关闭那个黑色命令行窗口即退出程序。

首次启动会加载模型、探测显卡，需要十几秒；之后模型有缓存，启动更快。

### 去回声 / 去混响（RVC 翻唱必看）

页面上「单曲分离」和「批量分离」都有一栏 **去混响 / 去回声预处理（可选 · RVC 翻唱前置）**，展开勾选后即变成两段式：

```
1/2 去混响 → 2/2 人声分离
```

- 输出里会多一份 `歌名_无混响.wav`，**RVC 翻唱请直接用这份做输入**。
- 原因：带混响 / 回声的输入会让翻唱模型把残响一起学成人声，出现闷糊、回声叠加等错误。
- 代价：多跑一遍同量级推理，本机实测 60 秒音频约 6.5 秒（与分离本身耗时相当）。
- 两个模型可选：
  - **标准 · 去混响更彻底（SDR 19.17）**：默认，推荐用于 RVC 翻唱；
  - **轻柔（SDR 18.81）**：去得更保守，保留更多原始质感。

### 性能设置（CPU / GPU 协同）

「环境」页 → 展开 **性能：CPU / GPU 协同设置与实测**：

- `CPU 线程数`（0 = 自动）：控制 torch 的 CPU 线程，写入 `perf.json`，重启后仍生效；
- `cudnn.benchmark`：固定分段长度下自动选最优卷积算法；
- **实测对比** 按钮：用本机同一段 60 秒音频、同一模型，跑 6 组配置，直接给出「秒/秒音频」对照表和结论，方便按自己机器的数字调参。

> 重要提示（本机实测结论，供参考，不代表你的机器）：CPU 线程数、cudnn.benchmark、batch_size 这几项差异 **小于 15%**，属于同一档次——因为瓶颈在 GPU 推理本身；真正影响最大的是 **`overlap`（重叠倍率）**，从 8 调到 32 会让同一段音频被重复推理更多份，耗时涨约 4 倍。建议保持默认 `overlap = 8`。

## 四、离线安装（目标电脑没有网络）

打包机执行 `python pack_dist.py --wheels` 可额外导出 `wheels\` 目录（体积很大，约 5 GB+）。把带 wheels 的包拷过去后：

```
python install_pack.py --mirror
```

或直接双击 `一键安装.bat` —— 安装脚本会优先使用 `wheels\` 里的本地包离线安装。

另外也可在打包机上把整个 `venv` 一起拷过去（体积大、但最省事），前提是目标机路径与原机差异不大；此方式非官方推荐，遇到问题优先用上面的 wheels 方式。

## 六、常见问题

**Q：双击 `一键安装.bat` 一闪而过？**
右键 → 编辑，或在该目录按住 Shift 右键「在此处打开 PowerShell」，执行 `.\一键安装.bat` 看报错；常见原因是没装 Python 或 Python 版本不在 3.10~3.12。

**Q：提示找不到 Python？**
去 python.org 装 3.12，安装时勾选 “Add python.exe to PATH”，然后重新双击 `一键安装.bat`。

**Q：分离很慢，显卡占用不高？**
先确认 `overlap` 是 4（**官方默认值**；原文写 8 是旧版延续下来的说法，已按代码修正）；再去「环境」页点「实测对比」看本机各项差异。若显示 `CUDA 可用：False`，说明显卡驱动过旧或没装 CUDA 版 torch，可重跑安装脚本，或手动执行：
```
venv\Scripts\python.exe -m pip install torch torchaudio torchvision --index-url https://download.pytorch.org/whl/cu128
```

**Q：装完打不开网页 / 端口被占？**
默认端口 7861。若被占用，可设置环境变量 `GRADIO_SERVER_PORT` 换端口，或关掉占用端口的程序。

**Q：输出文件夹在哪？**
包目录下的 `output\`。在页面上下载结果后，程序会自动清除输出目录里的那一份本机副本（避免双份占空间）；想手工清理可在页面点「清理本机副本」。

**Q：模型能换吗？**
可以。把新的 `.ckpt` / `.onnx` 放进 `models\`，重启程序后即可在「单模型」下拉里看到。程序不会联网下载模型，缺模型时启动正常但无法分离。
