【这是什么】人声 / 伴奏分离工具（Vocal Separator）
（原名 VocalSeparator）

用途：把一首歌拆成「人声」和「伴奏」两条音轨；也可用来去人声、提取伴奏。
大小：约 29.3 GB（含独立 Python 环境和 AI 模型）。

怎么用：
  双击 start.bat               → 启动程序
  双击 停止 VocalSeparator.bat → 关闭程序
  不需要了可运行 uninstall.py 卸载
注意：内含 venv 虚拟环境和 models 模型，缺一不可。
     文件夹名里的 “VocalSeparator” 不要删掉，停止脚本靠这个名字找进程。
